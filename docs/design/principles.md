# デザイン原則

## 目的

ライブの特設サイトは情報を読むだけのページではなく、視覚的な期待と物語を組み立てる媒体。情報設計を共通化し、**表現の軸を公演ごとに変える**。

## 5つの軸

1. **Typography:** セリフ/サンセリフ/縦組み、大きさ、可読性。装飾文字と本文は役割を分ける。
2. **Composition:** キャラクター、余白、装飾、背景の重心を決める。CSSグラフィックでもテーマに合う構図を選ぶ。
3. **Materials:** 夜空/花/紙/金属/ガラスなどの質感は色だけでなく、シェイプ、粒度、奥行きで表現する。
4. **Motion:** 出現/浮遊/スクロール連動/画面転換から目的に合うものだけ採用。動かさない美しさも残す。
5. **Interaction:** 固定CTA、カード、スライダー、ナビゲーションの形も各公演のモチーフに合わせる。操作の意味とアクセシビリティは維持する。

## 共通情報の骨格

Hero → Concept/Message → Information → News → Ticket → Merch → Album → Video → Profile → Footer が典型的な情報要素。順序は文脈によって変更可能。

## このデモでの3系統

- **BLOOM**: 花びら・明るい桃色・曲線と軽い浮遊感
- **NOCTURNE**: 夜空・静けさ・明朝系の見出し・繊細な光
- **PULSE**: ビビッドなライム・幾何学・斜めのラインと速いリズム

これは実在ライブのトレースではなく独自の世界観。色差分だけでない視覚文法の差を検証する。

## Accessibility / 運用

- `prefers-reduced-motion` を尊重し、明示的なモーション停止UIを用意。
- キーボードフォーカスを可視化。すべての意味のある操作には`button`/`a`を使う。
- 静止状態でも情報とリンクが欠けないようにする。
- モバイルで本文を読む際、装飾が文字に干渉しないことを優先。
